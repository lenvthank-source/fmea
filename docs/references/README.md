## Layout patterns implemented

- Primary process trains use a readable directional spine, explicit ports, equipment identity and adjacent labels.
- Material input/output and alternative branches use explicit labelled routes; decisions never invent outcome paths.
- Rework/recycle routes occupy outer routing lanes. Shared junctions are explicit; geometric crossings are not connections.
- Treatment and refining sequences use staged equipment groups and clear branch/merge structure.
- Manufacturing activity mode remains the default; general engineering mode uses explicit equipment choices.
