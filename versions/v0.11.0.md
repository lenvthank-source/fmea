# v0.11.0 — 2026-10-20
## Summary
Rebuilds DFMEA and Control Plan as controlled revision-owned engineering workflows while preserving legacy analyses and approved history. Adds reviewed source synchronization, complete document exports, explicit design relationships and transaction-level access/history safeguards. Public reference limitations remain visible; this release does not claim independently verified numerical standards conformity.

## Changes
### Features
- Dedicated DFMEA hierarchy, functions, interfaces, failure references, cause controls, evidence and separate reassessment; seven revisitable activities and synchronized engineering views.
- Phase-specific Control Plans with complete characteristics, sampling/reaction ownership, applicable safe-launch/system controls and explicit approved source baselines or justified exceptions.
- Preview/resolve/apply synchronization preserves manual decisions and flags source removals; full canonical lineage supports historical sources and no-PFMEA projects.
- Genuine whole-revision XLSX/native-model import preview and printable PDF output with stable identities, long Unicode and continuation rows.
### Fixes
- Tenant/project/type/trial checks, revision locks, stale-write conflicts, source dependencies and protected administrative history enforced transactionally.
- Complete revision/project cloning and readiness relationships; independent review/approval; no narration-based severity propagation or invented manufacturing autofill.
- Actual workspace sign-in, explicit missing-DFMEA state and narrow-screen editing layouts.
### Refactors
- Shared engineering access and typed document adapter; additive canonical models, evidence register, workflow skills, README indexes and portable handoff.
