# v0.8.2 — 2026-10-18

## Summary
Resolves critical user experience, ergonomics, and visual integrity issues across the FMEA platform. Configures Process Flow Diagram (PFD) operation steps to load completely collapsed by default, drastically reducing vertical space and table scroll. Deploys a Figma-style interactive 7-Step Walkthrough Guide docked globally as a persistent companion card with step-by-step route navigation and strictly two primary buttons (`Next` and `Skip All`). Purges all fake, UUID-truncated, and guest deletion records from Recent Activity & Audits, deriving 100% genuine quality engineering events directly from PostgreSQL revision and operation logs. Overhauls the landing page header and replaces mock visuals with a high-fidelity light-theme replica matching the actual enterprise app screens.

## Changes
### Features & UX Ergonomics
- **PFD Workspace Default Collapsed State**:
  - Initialized `collapsedSteps` in `PfdWorkspace.tsx` to include all step IDs on data fetch (`setCollapsedSteps(new Set(data.map((s: any) => s.id)))`).
  - Optimized table row padding (`py: 0.85`, `verticalAlign: middle`) to create crisp, single-line collapsed previews that maximize viewport efficiency on screens from 13" laptops to 27" monitors.
  - Retained instant "Expand All" / "Collapse All" batch controls and individual chevron expanders.

- **Figma-Style Linked 7-Step Interactive Guide**:
  - Rebuilt `FmeaTutorialGuide.tsx` from a single static popup into a docked floating companion card (`bottom: { xs: 72, sm: 80 }, right: 24`).
  - Linked guidance directly to each step of the AIAG-VDA 2019 quality analysis lifecycle:
    1. Step 1: Planning & 5Ts Scope (`/app/projects`)
    2. Step 2: Structure Analysis (`/app/projects/:id/pfd`)
    3. Step 3: Function Analysis & Tolerances (`/app/projects/:id/pfmea?tab=tree`)
    4. Step 4: Failure Analysis & Chains (`/app/projects/:id/linkage`)
    5. Step 5: Risk Analysis & AP Ratings (`/app/projects/:id/pfmea?tab=table`)
    6. Step 6: Optimization & Actions (`/app/actions`)
    7. Step 7: Documentation & Control Plan (`/app/projects/:id/control-plan`)
  - Enforced strictly **two primary action buttons** at every step: **`Next`** and **`Skip All`**.
  - Added step jump pills (Steps 1–7), a minimize-to-pill toggle (`_`), and mounted the guide globally in `AppShell.tsx` with `fmea:open_tutorial` custom event triggers.
  - Added route shortcuts in `router.tsx` (`/app/pfd/:id`, `/app/pfmea/:id`, `/app/linkage/:id`, `/app/control-plan/:id`).

- **Real Engineering Audit Feed (Zero Fake Data)**:
  - Enhanced backend `audit-log.service.ts` to exclude ephemeral maintenance records (`entityType: { notIn: ['user', 'session', 'token', 'auth'] }`), purging all guest creation/deletion clutter.
  - Preloaded `DocumentRevision -> Document -> Project` relationships to resolve real program names (`E vacuum pump`, `STATOR SOLENOID`), document types (`PFMEA`, `Control Plan`), and version strings.
  - Cleaned up `control_plan_row`, `pfmea_row`, and `process_step` activity labels into human-readable engineering descriptions with zero raw UUID strings.

- **Landing Page Header & Actual App Screen Hero Mockup**:
  - Removed `Warming API...` / `RLS Active • Live API` badge and mobile warming indicators from `SiteHeader.tsx`.
  - Overhauled `FmeaStudioPreview.tsx` to faithfully replicate the actual FMEApex light enterprise interface with real project context: `E vacuum pump (Part No: 861000000, Rev: 1.0, Cust: TML, Safe Launch)`.
  - Added interactive tabs for Process Flow Diagram (PFD), PFMEA 7-Step Grid, Control Plan (CP) Sync, and Workspace Overview with real engineering parameters.
