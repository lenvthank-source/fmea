# v0.5.1 — 2026-09-01
## Summary
Implements 8 key FMEA workflow and quality enhancements: Safe Launch hierarchical selector under Pre-Launch, Concerned Key Contact and Document Latest Change Level label alignments, Drawing Revision Date placement, removal of preliminary/final flags, Admin Panel navigation fix for rating scale customization, sticky document header locking during overlay interaction, rebuilt Failure Details window with inline editable prevention/detection controls and action sub-table, Add Action dialog with 1-click rating scale guidelines, and Excel report fixes (3 signature blocks in PFD & PFMEA, removal of Work Element column, individual cause sub-row alignment with merged parent cells).

## Changes
### Features
- **Safe Launch 2-level selector:** `frontend/src/features/projects/ProjectList.tsx:1127` & `frontend/src/features/projects/ProjectSettings.tsx:566` Document Type selection converted to a two-level hierarchy (Prototype, Pre-Launch with nested Safe Launch checkbox, Production). `DocumentHeader.tsx:78` recognized Safe Launch chip badge.
- **Rebuilt Failure Details Window (Image 2):** `frontend/src/features/pfmea/components/FailureDetailWindow.tsx:1` updated with breadcrumb hierarchy (`Part > [PS] Step > [ƒ] Function > [F] Failure Mode > Highest Severity`), Causes/Effects tabs, toolbar buttons (`Edit Cause`, `Link/Unlink Cause`, `Add Action`, `Edit Action`, `Delete Action`), Causes table (`Cause Description | Prevention Control | OCC | Detection Control | DET | AP | FC`) with inline editable controls auto-saving via `PATCH /structure-failures/:id`, and nested Action sub-table.
- **Add / Edit Action Dialog with Guidelines (Image 3):** `frontend/src/features/pfmea/components/FailureDetailWindow.tsx:420` complete action modal with Prevention/Detection/Action Taken multiline inputs, Target/Completion date inputs with clear `[X]` buttons, Responsible Person input with `Add/Edit Core Team` button, Status dropdown, Remarks, and After Action S/O/D inputs with interactive `[Guideline]` buttons opening full 1–10 criteria modal from `/rating-scales` for 1-click selection.
- **PFMEA Excel report per-cause sub-rows:** `frontend/src/features/reports/ReportExporter.tsx:465` rewritten to render each cause on its own distinct sub-row with paired prevention/detection controls and vertically merged parent columns.

### Fixes
- **Admin Panel navigation:** `frontend/src/components/Layout/AppShell.tsx:28,115,410` fixed Administration permission check from `admin.users` to `admin.config` and filtered navigation items by `hasPermission`, resolving route mismatch and enabling direct navigation to `/admin` for editing S/O/D rating scales criteria.
- **Sticky document header:** `frontend/src/components/DocumentHeader.tsx:78` pinned header card with `position: sticky, top: 0, zIndex: 1100`, keeping part details locked and unblurred during overlay dialogs and scrolling.
- **PFD & PFMEA signature cleanup:** `frontend/src/features/reports/ReportExporter.tsx:387,465` removed duplicate "Approved By" signature block from both PFD and PFMEA Excel exports, standardizing to 3 clean boxes: Prepared By, Checked By, Approved By.
- **Work Element column removal:** `frontend/src/features/reports/ReportExporter.tsx:465` removed extra "Work Element (4M)" column from PFMEA Excel export headers and column configurations (23 columns: A to W).

### Refactors
- **Field alignment:** `frontend/src/features/projects/ProjectList.tsx` & `ProjectSettings.tsx` renamed "Key Contact / Phone" -> "Concerned Key Contact" and "Latest Change Level" -> "Document Latest Change Level"; grouped Drawing Revision Date alongside Dwg No.
- **Removed preliminary/final status flags:** Removed preliminary and final radio controls from project creation and settings forms.
