# v0.12.1 — 2026-10-21

## Summary
Restored authentic classic manufacturing symbols (Operation, Inspection, Transport, Storage, Decision, Rework, Combined) with high-density ergonomics in the PFD table and Browse Shapes dialog. Eliminated table row inflation, simplified multi-activity selection, and added atomic step patching for symbol changes.

## Changes
### Features
- Restored original classic manufacturing palette as default (Operation = circle, Inspection = square, Transport = arrow, Storage = inverted triangle, Decision = diamond, Rework = pentagon outline without text, Combined = circle-in-square).
- Added 7 stable classic symbol IDs (`manufacturing.classic.*`) and route markers (`marker.wip`, `marker.reject`), generating 417 identical symbols across backend and frontend catalogs.
- High-density BrowseShapesDialog featuring instant 1-click manufacturing symbol selection, optional route marker toggles, and secondary 'More symbols' library tab.
### Fixes
- Compact PFD table cell: eliminated row height inflation by replacing multi-paragraph text diagnostics with single primary action button, marker tags, and a compact 'Needs review' chip with hover tooltip.
- Enforced single primary manufacturing activity selection to prevent confusing multi-step state collisions.
- Atomic multi-field PATCH updates (`handleAtomicStepChange`) in PfdWorkspace to synchronize `stepType`, `manufacturingSymbolId`, and `flowIcons` in a single request.
### Refactors
- Cleaned SVG vector paths in `scripts/build-pfd-symbols.py` for classic manufacturing outlines.
- Synchronized symbol utilities in `frontend/src/features/pfd/utils/pfdSymbols.ts` and updated unit test suite.
