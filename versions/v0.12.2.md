# v0.12.2 — 2026-10-21

## Summary
Restored multi-flow symbol support in PFD tables per industrial manufacturing standards (AIAG-VDA 2019 / ASME Process Charts). Process steps now support multiple simultaneous active flow activities (Operation, Inspection, Transport, Storage, WIP, Decision, Rework, Reject) with side-by-side SVG vector badges in table rows, non-destructive multi-select editing, and formal architectural governance invariants.

## Changes
### Features
- Added support for multiple simultaneous flow symbols per PFD table row, rendered side-by-side as crisp SVG vector badges with tooltips.
- Multi-select symbol selection in BrowseShapesDialog: toggles any combination of standard flow activities with visual check indicators and summary badge count.
- Multi-symbol toggle support in Step Creation and Edit Drawers (PfdWorkspace, StepFormDialog).
- Formatted all active flow symbols in PFD Excel exports (`pfdFormattedActivities`) while preserving singular canvas node geometry.

### Fixes
- Eliminated artificial single-symbol restriction in PFD table rows caused by conflating flowchart canvas node geometry with worksheet activity attributes.
- Removed destructive flowIcon clearing when changing step types; flow activities are toggled non-destructively.
- Added smart fallback `derivePrimaryStepType` for diagram node geometry (e.g. Operation + Inspection -> Combined circle-in-square).

### Refactors
- Codified Rule 2.1.1 (PFD Flow Symbol Multiplicity) in `.agents/AGENTS.md` §2.1.
- Codified hard invariant in `.agents/agents/pfd/AGENT.md` forbidding single-symbol restrictions.
- Synchronized flow symbol catalog utilities in `frontend/src/features/pfd/utils/pfdSymbols.ts` and expanded test suite to 28 passing unit tests.
