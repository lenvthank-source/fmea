# v0.2.3 — 2026-08-26
## Summary
Patch fixing Actions `D.map` crash, project nav cleanup, Fab duplicate ergonomic fix, admin-editable Severity/Occurrence/Detection scales (simple groups), and login 5× perf regression without pg_trgm.
