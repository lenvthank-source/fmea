# v0.9.0 — 2026-10-19
## Summary
Rebuilt the FMEApex homepage around connected engineering data and carried its visual identity through sign-in and the program dashboard. Trial entry opens the authenticated app directly, contextual walkthroughs follow actual controls, and workspace activity now uses genuine audit events scoped to accessible programs.

## Changes
### Features
- Interactive homepage story covering DFMEA structure, PFMEA relationships, shared controls, and verified mitigation, with an illustrative product preview.
- Matching sign-in/dashboard theme, compact program-first layout, and responsive trial identity.
- Contextual creation and seven-step workflow coachmarks with real form validation and project-aware navigation.
- Portable cross-agent handoff documentation, installed design skills, and a refreshed Graphify knowledge graph.
### Fixes
- Route Try FMEApex / Try it out directly through guest initialization with retryable failures.
- Poll the existing root health endpoint and verify its JSON status.
- Remove duplicate guide chrome and trial archive navigation; improve phone layout.
- Return only viewer-scoped recorded activity with real project attribution, refresh/error states, and collection-POST entity IDs.
### Refactors
- Consolidate the shared MUI theme and scoped native UI styles.
- Keep walkthrough navigation separate from enforced FMEA completion gates.
- Require Graphify refresh after each logical code-change batch and synchronize handoff documentation.
- Synchronize root/backend/frontend package and lockfile version metadata at 0.9.0.
