# v0.15.0 — 2026-10-23

## Summary
Introduces one-click Design FMEA (DFMEA) initialization for process-only programs, seamlessly bridging manufacturing projects into connected design failure chains and controls. Simultaneously introduces the compact Control Plan workspace layout, collapsing redundant titles, grouping Review, Export, and Plan options into dense menus, providing an accessible requirement-profile popover, and delivering an ergonomic 210px operation navigator canvas.

## Changes
### Features
- One-Click Initialize Design FMEA: Added transactional backend initialization endpoint `POST /api/v1/projects/:id/initialize-dfmea` and active workspace button in `DfmeaWorkspace.tsx`, seamlessly provisioning draft revision 1.0 and canonical `emptyDfmea()` JSON models for projects originally configured without DFMEA.
- Compact Control Plan Workspace Bar: Added `ControlPlanToolbar.tsx` with compact revision/phase/count/save strip, grouped Review, Export, and Plan options menus, and collapsible source change reconciliation drawer.
- Accessible Requirement Profile Popover: Replaced static requirement-profile banner with an accessible inline information popover, reducing vertical footprint while keeping compliance notices available.
- Streamlined Operation Navigator: Condensed `ControlPlanV2View.tsx` with a responsive 210px operations navigator, dense characteristic and control cards, and clean wrapping layouts.

### Fixes
- Missing DFMEA Dead-End: Replaced the static dead-end panel ("No Design FMEA in this program") with active initialization affordance, loading feedback, archive protection, and permission validation.
- Archived Program Access Guard: Prevented mutation attempts on archived programs during DFMEA initialization with strict 403 Forbidden checks.

### Refactors
- Workspace Header Consolidation: Removed duplicate "Control Plan V2" title and redundant metadata tabs from `ControlPlanWorkspace.tsx`, standardizing on a single clean engineering heading.
- Centralized Plan Actions: Grouped PDF/XLSX export, JSON report generation, review decision history, and validation runs into dropdown option menus.
