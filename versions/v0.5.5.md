# v0.5.5 — 2026-09-01
## Summary
Eliminates duplicate '+' icon rendering on the dashboard action button and completely overhauls the Create / Edit Quality Program modal into a space-optimized Shadcn Admin layout with a 3-pill horizontal step progress tracker, interactive phase selection cards, clean 2-column input grids without margin clumping, and a redesigned delete confirmation dialog.

## Changes
### Fixes
- **Duplicate '+' Icon on Create Project Button:** `frontend/src/features/projects/ProjectList.tsx:606` removed duplicate '+' character from button text that caused '+ + Create Project' rendering alongside `startIcon={<AddIcon />}`. Also cleaned up Quick Shortcuts card button.
- **Form Congestion & Margin Normalization:** `frontend/src/features/projects/ProjectList.tsx:1350` removed all legacy `margin="normal"` overrides across form text fields, establishing uniform `spacing={2.5}` grid alignment with `size="small"` rounded inputs to eliminate erratic vertical clumping.

### Refactors
- **Create / Edit Quality Program Modal Overhaul:** `frontend/src/features/projects/ProjectList.tsx:1320` replaced sprawling `80vw` unstyled dialog with a modern `maxWidth="md"` Shadcn Admin modal:
  - Header bar with AIAG-VDA 2019 subtitle and clean close icon button `✕`.
  - 3-Pill Horizontal Step Tracker (Program & Part → Plant & Customer → Document Control & CFT) with completed step checkmarks.
  - Step 1: Interactive 3-card phase selector (`Prototype`, `Pre-Launch`, `Production`) with inline `Safe Launch Checklist` toggle and subtle template replication card.
  - Step 2: Clean 2-column plant and customer context fields with required indicators.
  - Step 3: Compact auto-derived document numbers (`PFD`, `PFMEA`, `Control Plan`), date pickers, CFT member tags, and optional approval sign-offs.
  - Footer bar with Cancel, Back, and dark `#09090b` primary action button.
- **Delete Confirmation Dialog:** `frontend/src/features/projects/ProjectList.tsx:1312` redesigned delete confirmation modal with rounded 14px paper, clean warning typography, and red `#ef4444` destructive button.
