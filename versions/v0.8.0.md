# v0.8.0 — 2026-10-18

## Summary
Resolves all 12 security vulnerabilities (4 moderate, 6 high, 2 critical) flagged during the backend production container build. Upgrades vulnerable transitive dependencies across proxy-addr, handlebars, multer, fast-uri, brace-expansion, browserslist, and qs, and introduces a targeted js-yaml package override to eliminate sprintf-js/argparse denial-of-service risks, bringing backend npm audit to 0 vulnerabilities.

## Changes
### Fixes
- **Critical & High Security Vulnerability Resolution**:
  - `proxy-addr` (critical): Patched IP spoofing vulnerability via IPv4-mapped IPv6 trust subnet.
  - `handlebars` (critical): Resolved JavaScript injection vulnerabilities (AST type confusion and prototype check bypass).
  - `multer` & `@nestjs/platform-express` (high): Patched denial of service vulnerabilities via crafted multipart field names and file size limit race conditions.
  - `fast-uri` (high): Patched host confusion and SSRF vulnerabilities.
  - `brace-expansion` (high): Patched exponential-time DoS and uncontrolled recursion.
  - `browserslist` (high): Patched unbounded memory growth and prototype write.
  - `qs` (moderate): Patched array-limit bypass and DoS vulnerabilities.
- **Transitive Dependency Override**:
  - Added `"overrides": { "js-yaml": "^4.1.0" }` in `backend/package.json` to resolve `sprintf-js` unbounded precision DoS from `@istanbuljs/load-nyc-config` -> `argparse`.
  - Achieved `found 0 vulnerabilities` across all audit levels (production and development).
