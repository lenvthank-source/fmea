# v0.5.2 — 2026-09-01
## Summary
Transforms the internal application first screen into the modern, space-optimized Shadcn Admin dashboard layout (header, tab navigation, 4-card bento KPI row, 2-column overview with recent quality activity and quick shortcuts), enhances AppShell navigation with quick search and compact borders, and completes the Ventriloc design theme replication (warm ivory/gray/orange palette, interactive Power BI / Fabric / FMEA dashboard showcase, floating capsule header, infinite partner marquee ticker, and stacked sticky cards).

## Changes
### Features
- **Shadcn Admin Dashboard First Screen:** `frontend/src/features/projects/ProjectList.tsx:563` transformed main workspace screen into Shadcn Admin layout:
  - Top header with `Dashboard` title, subtitle, `Download Overview` button, and `+ Create Project` primary dark button (`#09090b`).
  - Segmented pill tab bar (`Overview` and `Archived Programs`).
  - 4-Card Bento KPI Grid: Active Programs (`Layers` icon, quarterly trend), Production Phase (`ShieldCheck` icon, serialized lines), Prototypes & Launches (`TrendingUp` icon, gated validation), and Audit Readiness (99.8%, 21 CFR Part 11 compliant).
  - Two-Column Overview Layout (8/12 + 4/12 split):
    - Left column: Search input with `⌘K` shortcut badge, phase filter pills (`All`, `Prototype`, `Pre-Launch`, `Safe Launch`, `Production`), View mode switcher (Grid / Compact Table), and Shadcn-styled program cards.
    - Right column: Recent Activity & Audits widget (Shadcn "Recent Sales" pattern) displaying latest revision locks, CFT digital signatures, and closed corrective actions with user avatars; plus Quick Quality Shortcuts.
- **Ventriloc Interactive Dashboard Showcase:** `frontend/src/components/site/VentrilocDashboard.tsx:1` Power BI / Fabric / FMEA studio showcase with live telemetry, Pareto distribution bar chart, station telemetry selector, Action Priority matrix, and 4 tabs (`Executive BI`, `PFD ↔ PFMEA`, `Risk Heatmap`, `Actions`).
- **Ventriloc Floating Header:** `frontend/src/components/site/SiteHeader.tsx:1` floating capsule navbar with mega dropdown, bilingual language switcher (`[FR | EN]`), and vermilion orange CTA button (`btn-ventriloc-primary`).
- **Ventriloc Landing Page & Stacked Cards:** `frontend/src/features/landing/LandingPage.tsx:1` hero headline with laiton brush underline, infinite partner marquee ticker (`@keyframes ticker`), and stacked sticky cards (`pb-row-services`).
- **Ventriloc Dark Footer:** `frontend/src/components/site/SiteFooter.tsx:1` dark charcoal `#202020` footer with compliance badges, bilingual links, and newsletter signup.

### Fixes
- **CSS @import ordering:** `frontend/src/index.css:1` reordered `@import url(...)` font imports to precede `@import "tailwindcss";`, resolving Vite build warnings.
- **Unused prop & slotProps fixes:** Fixed unused `compact` prop in `VentrilocDashboard.tsx` and updated `ProjectList.tsx` search input from deprecated `InputProps` to MUI v6 `slotProps.input`.

### Refactors
- **AppShell Header & Sidebar:** `frontend/src/components/Layout/AppShell.tsx:210,344` modernized top bar to compact 52px height with workspace badge (`/ FMEApex Quality Workspace`), center search pill (`⌘K`), bell notifications, and user popover; updated sidebar with clean `#e4e4e7` borders and compact 36px buttons.
- **ProductPage Dashboard Upgrade:** `frontend/src/features/product/ProductPage.tsx:6,51` updated hero to embed `VentrilocDashboard` and Ventriloc CTA pill buttons.
