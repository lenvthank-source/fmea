# v0.3.3 — 2026-08-27
## Summary
Introduces full 22-column AIAG-VDA 2019 PFMEA Excel Import Wizard with cascading parent cell forward-fill and auto-structure tree synchronization, fixes PFD import stepNumber validation and regex parsing across prefixed formats, swaps Add Failure Cause dialog fields to place Prevention/Detection controls above ratings, resolves dropdown menu overlap across all failure dialogs with downward anchoring and scrolling, optimizes Excel Import Wizards to dedicate >85% viewport space to data grids, and adds a sleek floating translucent horizontal scrollbar in PFMEA Report View.
## Changes
### Features
- **AIAG-VDA 2019 22-Column PFMEA Excel Import Wizard:** `backend/src/modules/pfmea/pfmea-row.service.ts:725` & `frontend/src/features/pfmea/components/PfmeaExcelImportWizard.tsx:1` batch import endpoint (`POST /revisions/:id/pfmea-rows/batch-import`) and 5-step wizard supporting all 22 columns (Structure/Item, Focus Function, Failure Mode, Effects, S, Causes, Prevention/Detection Controls, O, D, AP, FC, Prevention/Detection Actions, Resp/Dates, Revised S/O/D/AP, Status, Remarks) with merged cell forward-fill and database/structure tree transaction syncing.
- **Floating Horizontal Scrollbar Controller:** `frontend/src/features/pfmea/PfmeaWorkspace.tsx:125,1765` sleek glassmorphic sticky horizontal scroll controller pill with bidirectional scroll synchronization, smooth ◀ / ▶ 350px pan buttons, dynamic percentage slider, and quick-jump category chips (`Steps`, `SOD Risk`, `Actions`).
- **Import Wizard Screen Viewport Optimization:** `frontend/src/features/pfd/components/ExcelImportWizard.tsx:949,1012,1125,1330` and `PfmeaExcelImportWizard.tsx:370,440,560` converted wizards into `96vw x 92vh` full-bleed modals with compact toolbars, dedicating >85% of vertical viewport height directly to data tables.
### Fixes
- **PFD Import `stepNumber` Validation & Multi-Format Parsing:** `backend/src/modules/pfd/dto/create-step.dto.ts:5` marked `stepNumber` as `@IsOptional()`, and `frontend/src/features/pfd/components/ExcelImportWizard.tsx:62,192,481,711` added multi-format regex support for `OP # 01`, `OP#10A`, `Step 10:`, `ST_01`, and guaranteed sequential fallback auto-numbering (`OP10`, `OP20`...).
- **Add Failure Cause Field Interchanging:** `frontend/src/features/pfmea/components/AddFailureDialog.tsx:394` swapped field positioning under Cause mode to place Prevention/Detection Controls and Filter Code on Row 1, and Occurrence/Detection Ratings on Row 2.
- **Select Dropdown Menu Overlap & AutoFocus Jumps:** `frontend/src/theme/muiSelectConfig.ts:1` & `frontend/src/features/pfmea/components/RatingDropdown.tsx:78` configured `maxHeight: 220`, `overflowY: 'auto'`, downward anchoring (`anchorOrigin: { vertical: 'bottom', horizontal: 'left' }`), `autoFocus: false`, and `disableAutoFocusItem: true` to prevent menus from flipping upwards and covering modal buttons.
### Refactors
- **Structure Tree Batch Sync:** `backend/src/modules/pfmea/pfmea-row.service.ts:860` integrated `StructureFunction` and `StructureFailure` record creation scoped to `tenantId` and `projectId` during batch PFMEA imports.
- **Toast Severity Extension:** `frontend/src/components/Toast/ToastProvider.tsx:4` extended `ToastSeverity` type to include `'success'`.
