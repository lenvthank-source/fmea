# v0.10.1 — 2026-10-19
## Summary
Hardens the Process Flow Diagram (PFD) workspace and Excel exporter against rolling container deployments and unhydrated authentication states. Automatically derives the sequence flow layout when the backend graph endpoint is unmapped or returns 404, guards unauthenticated step queries, and synchronizes project sub-resource visibility.

## Changes
### Fixes
- **Resilient PFD Graph Fallback**: Updated `PfdEngineeringCanvas.tsx` to handle HTTP 404 responses gracefully by returning `{ graph: null, version: 0, writable: true }`, allowing the canvas to fall back to auto-derived sequence flow (`derivePfdGraph(steps)`) without throwing fatal errors.
- **Unhydrated Token Guard in PFD Workspace**: Updated `fetchSteps()` in `PfdWorkspace.tsx` to verify both `revisionId` and `token` prior to dispatching network requests, preventing unauthenticated `[anon]` queries with `Bearer null`.
- **Fault-Tolerant PFD Report Export**: Updated `loadPfdExport()` in `ReportExporter.tsx` with a non-fatal fallback so Excel workbooks export cleanly even if persisted topology responses fail.
- **Admin Project Document & Revision Access**: Corrected `ProjectController` and `ProjectService` so `findDocuments` and `getRevisions` respect `allowArchived` and `isAdmin`, enabling administrators to inspect archived guest sandbox documents.
- **Health Check Path Resolution**: Excluded `api/v1/health` from NestJS global prefixing in `main.ts`, eliminating recurring 404 warnings from background keep-awake pings.
