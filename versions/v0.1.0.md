# v0.1.0 — 2026-08-26
## Summary
First functional release implementing core handwriting requests: versioning system, UI dropdown fixes, Description/Specification column removal, Excel export border/flow-icon fixes, Failure Linkage zoom/pan, Project replication with prefill & audit, Work-element retention architecture fix.

## Changes
### Features
- **Versioning system** (root `package.json` = 0.0.0, `versions/` folder, AGENTS.md rule)
- **Project replication** — "Duplicate for new customer" menu action pre-fills full AIAG quality header, clones selected document types (PFD/PFMEA/DFMEA/Control Plan), writes audit log `action:'replicate'`
- **Excel Import Wizard backend** — new `POST /revisions/:id/pfd-steps/batch` for bulk step creation
- **Failure Linkage zoom/pan** — mouse-wheel zoom-to-cursor, drag pan, toolbar (+/−/Fit %), auto fit-to-view on load
- **Work-element retention** — merge-not-replace sync on PFD edit, repo import & structure-linkage append to PFD master, no-orphan invariant

### Fixes
- **Dropdowns in dialogs** — shared `dialogSelectMenuProps` (anchor bottom-left, transform top-left) applied to all dialog Selects
- **Removed Description/Specification column** from AddFunctionDialog multi-function tab (frontend-only; backend never persisted it)
- **Excel export borders** — whole-table thick outer border (A1:H<lastRow> / A1:X<lastRow>), thin borders on title/spacer/legend rows, signature merges normalized to A:B/C:D/E:F/G:H
- **Excel flow icons unified** — legend/symbols now use exact PFD UI glyphs (`⇨ ▽ ▽ ▲ ◯ □ ◇ Ⓡ ✕`) matching `pfdIconMap.ts`
