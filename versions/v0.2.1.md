# v0.2.1 — 2026-08-26
## Summary
Patch release fixing Render deploy crash (RevisionGuard DI) and adding global warning/error feedback for blocked/failed user actions. No schema changes; all writes now surface as bottom-center Snackbar (warning for locked/draft/permission, error for server/validation) while retaining top Alert banners.
## Changes
### Fixes
- Fix `UnknownDependenciesException: RevisionGuard` crash on Render — make `RevisionGuard` globally available via new `CommonModule` (`@Global()`) imported in `AppModule` (`backend/src/common/common.module.ts:1`, `backend/src/app.module.ts:24,29`). Verified `PfdService`, `PfmeaRowService`, `ControlPlanRowService` now resolve.
- Surface silent-click failures as user-visible feedback — introduce global `ToastProvider` (`frontend/src/components/Toast/ToastProvider.tsx:1`, `snackbar bottom-center`, `warning 6000ms` / `error 7000ms`, `variant filled`, `getToastSeverity()` maps locked/draft/permission -> warning else error).
### Features
- Global `ToastProvider` + `lib/api.ts:parseApiError` — warning/error-only toasts (no success spam as requested). Wired in `frontend/src/App.tsx:3,13` (`<ToastProvider><AuthProvider>`).
- Inline and dialog error surfacing for all user-initiated writes: PFD `handleFieldChange`/`renderMultiInputCell`/`handleSaveFlowIcons`/`handleCreateStep`/`handleDuplicateStep`/`handleDeleteStep`/`handleDrop` (`frontend/src/features/pfd/PfdWorkspace.tsx:167,302,324,356,414,446,480,517,600,666,704,730,771`), PFMEA `handleSyncTreeWithTable`/`handleSaveManageAction`/`handleAddRow`/`handleDelete*` (`frontend/src/features/pfmea/PfmeaWorkspace.tsx:81`), Project list `fetchProjects`/`handleDeleteProject`/`handleArchiveProject`/`handleRestoreProject`/`handleCreate`/`handleUpdate` (`frontend/src/features/projects/ProjectList.tsx:58`), plus `ControlPlanWorkspace`, `DfmeaWorkspace`, `ActionsDashboard`, `LinkageMap`, `RepositoryPage`, `ImportTargetDialog`, `EditPackageDialog`, `AddFunctionDialog`, `AddFailureDialog`, `MultiAddWorkElementDialog`, `FailureLinkageModal`, `FailureDetailWindow`.
### Refactors
- Add `frontend/src/lib/api.ts:1` (`parseApiError`, `getAuthHeaders`, `apiFetch` wrapper) for consistent backend message extraction.
