# v0.5.7 — 2026-09-01

## Summary
Fragmented columns 7 through 23 (Failure Causes, Current Controls Prevention/Detection, OCC, DET, AP, FC, Prevention/Detection Actions, Responsibility & Target Date, Action Taken & Completion Date, Revised S/O/D/AP ratings, Status, Remarks) into independent sub-rows across PFMEA Excel Export, Excel Import, and Report View. Removed the Work Element (4M) column from the on-screen Report View grid to establish 1:1 parity with the exported Excel report. Overhauled the PFMEA workspace, top toolbar, and all child dialogs (FailureDetailWindow, AddFailureDialog, AddFunctionDialog, MultiAddWorkElementDialog, FailureLinkageModal, and PfmeaExcelImportWizard) to the Space-Optimized Shadcn Admin theme.

## Changes
### Features
- **PFMEA Export Fragmented Causes Sub-Rows**: In `ReportExporter.tsx`, only parent columns 1 through 6 (`#`, `Structure / Item`, `Function / Focus Element`, `Failure Mode`, `Potential Effects`, `SEV`) are merged vertically per Failure Mode. All subsequent 17 columns (7 to 23: Failure Causes, Prevention Control, OCC, Detection Control, DET, AP, FC, Prevention Action, Detection Action, Responsibility & Target Date, Action Taken & Completion Date, SEV rev, OCC rev, DET rev, AP rev, Status, Remarks) remain unmerged and render individual sub-rows per cause and action.
- **PFMEA Report View Grid Parity & Fragmented Rows**: In `PfmeaWorkspace.tsx`, removed `Work Element (4M)` from TableHead and body cells matching the Excel export. Implemented multi-cause sub-row rendering with `rowSpan` applied only to parent columns and fragmented cells across columns 7 to 23.
- **Shadcn Admin Top Toolbar**: Upgraded PFMEA view switcher from legacy underline tabs to the space-optimized `#f4f4f5` segmented pill tabs (`Tree View` vs `Report View`) with live count chips and dark `#09090b` primary buttons.
- **Excel Import Fragmented Row Support**: Updated `PfmeaExcelImportWizard.tsx` auto-mapping synonyms with en-dash, hyphen, and abbreviation variants (`current control – prevention`, `current control – detection`, `sev rev`, `sev (rev)`, `occ rev`, `occ (rev)`, `det rev`, `det (rev)`, `ap rev`, `ap (rev)`).

### Refactors
- **Space-Optimized Shadcn Admin Child Dialog Overhaul**:
  - `FailureDetailWindow.tsx`: Upgraded root dialog container (`borderRadius: '14px'`, `#ffffff` paper, `border: '1px solid #e4e4e7'`), clean breadcrumb header, `#f4f4f5` segmented pill tabs (`Effects` vs `Causes & Actions`), `#fafafa` table headers, and modernized Add Action and Rating Guideline modals.
  - `AddFailureDialog.tsx`: Removed red top border, added title bar with role tag, CloseIcon, `#f4f4f5` segmented pill tabs (`Single Failure` vs `Multiple Failures`), and `#09090b` primary buttons.
  - `AddFunctionDialog.tsx`: Removed green top border, added parent type chip, CloseIcon, `#f4f4f5` segmented pill tabs (`Single Function` vs `Multiple Functions`), and `#09090b` primary buttons.
  - `MultiAddWorkElementDialog.tsx`: Clean title bar with 4M tag, segmented pill tabs (`Single Element`, `Multiple (Batch)`, `Repository Package`), and `#09090b` primary buttons.
  - `FailureLinkageModal.tsx`: Modernized network connection header with LinkIcon badge, CloseIcon, and `#09090b` Save button.
  - `PfmeaWorkspace.tsx`: Modernized Add PFMEA Analysis Row dialog, Manage Action dialog, and PFD Step Import prompt dialog.
