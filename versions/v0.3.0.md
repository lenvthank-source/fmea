- `PATCH /projects/revisions/:id` now rejects non-draft and locked + validates dates (stricter). `POST /projects/revisions/:id/approve` now writes `approvedAt` as well as `lockedAt`.
- PFD multi-value Backspace now requires confirmation (was silent splice + PATCH) — keyboard flow slightly slower but meets “always confirm deletions” ask; Undo is next backlog.
