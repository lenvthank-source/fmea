# v0.3.1 — 2026-08-27
## Summary
Resolves PFD Excel import error on legacy .xls files via universal SheetJS parser, fixes Failure Linkage 3-column horizontal flow and bezier curves, adds sharp slate visual divider between diagram and selection panels, removes duplicate plus '+' signs from Add buttons across all dialogs, and introduces lightweight fluid glassmorphism button styling.
## Changes
### Fixes
- **PFD Excel Import (.xls support):** `frontend/src/features/pfd/components/ExcelImportWizard.tsx:325` replaced ExcelJS reader with `XLSX.read(arrayBuffer, { type: 'array' })` from SheetJS. Now universally parses legacy `.xls` (BIFF8 binary, XML, HTML tables) and `.xlsx` files without `"No worksheet found"` errors, scanning up to 25 rows with weighted synonym matching to detect table headers automatically.
- **Failure Linkage 3-Column Flow & Layout:** `frontend/src/features/pfmea/components/FailureLinkageModal.tsx:446` restored horizontal flex layout (`display: 'flex', flexDirection: 'row'`) on zoom/pan container. Positioned Higher Level Effects on left (30%), Failure Mode in center (32%), and Lower Level Causes on right (30%). Fixed SVG connector coordinates from effect card right-edges (`r.right`) to center box left-edge, and center box right-edge to cause card left-edges (`r.left`) with `overflow: 'visible'`.
- **Double Plus `+ +` on Add Buttons:** Removed redundant `+` in button text across all modal dialogs where `startIcon={<AddIcon />}` is rendered:
  - `frontend/src/features/pfmea/components/AddFailureDialog.tsx:452,598` — `+ Add Row` ➔ `Add Row`
  - `frontend/src/features/pfmea/components/AddFunctionDialog.tsx:326` — `+ Add Row` ➔ `Add Row`
  - `frontend/src/features/pfmea/components/MultiAddWorkElementDialog.tsx:256` — `+ Add Row` ➔ `Add Row`
  - `frontend/src/features/repository/EditPackageDialog.tsx:275,349,419` — `+ Add Function` ➔ `Add Function`, `+ Add Cause` ➔ `Add Cause`
### Features
- **Sharp Slate Visual Border Divider:** `frontend/src/features/pfmea/components/FailureLinkageModal.tsx:420` added prominent `borderRight: '2px solid #CBD5E1'` with subtle inset shadow separating the Network Diagram canvas from the dual-tree sidebar.
- **Fluid Glassmorphic Button Design:** `frontend/src/theme/ColorModeContext.tsx:71` added lightweight CSS-only glassmorphic styling for MUI buttons (`backdropFilter: 'blur(8px)'`, translucent backgrounds `rgba(255, 255, 255, 0.75)`, refined borders `rgba(15, 23, 42, 0.14)`, and smooth hover micro-elevation).
