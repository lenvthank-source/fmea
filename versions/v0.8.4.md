# v0.8.4 — 2026-10-18

## Summary
Refines the Excel Retirement Showcase (`ExcelRetirementShowcase.tsx`) and full landing page layout to completely eliminate jarring letterboxed dark void containers, replacing them with a unified, high-craft, light enterprise aesthetic. Streamlines component architecture, cleans unused imports, ensures 0 TypeScript/Vite bundling warnings, and completes responsive layout verification across 13" laptop to 27" desktop viewports.

## Changes
### Features & UX Ergonomics
- **Full-Width Light Enterprise Architecture for Excel Showcase**:
  - Eliminated the isolated `bg-slate-950` letterbox container that caused jarring visual disjointment on the front page.
  - Redesigned the 3 visualization modes (`Old Excel Sheet`, `FMEApex Engine`, `Side-by-Side`) into a cohesive, border-aligned light enterprise canvas matching the rest of the application.
  - Preserved authentic Excel spreadsheet styling with `#107C41` header, `#REF!` formula bar, and clear red callouts for lethal hazards skipped due to arbitrary `<100` RPN cutoffs.
  - Streamlined the interactive 4-card vulnerability strip below the canvas with high contrast and intuitive selection states.
- **Code Hygiene & Build Integrity**:
  - Removed unused imports (`ArrowRight` in `ExcelRetirementShowcase.tsx`).
  - Verified 0 TypeScript compilation errors in backend (`npx tsc --noEmit`) and frontend (`tsc -b && vite build`).
  - Verified visual layout across multiple viewport breakpoints (1440x900, 1920x1080) using Puppeteer MCP.
