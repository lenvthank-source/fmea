# v0.14.0 — 2026-10-23

## Summary
Retires legacy Control Plan Version 1 (V1) entirely across database, backend, and frontend, standardizing permanently on Schema Version 2 (V2). Drops relational prototype tables (`control_plan_row`, `control_plan_pfmea_link`), eliminates the ~700-line legacy flat-line workspace table and modals, fixes write-access and archived project 403 authorization guards, and renders `ControlPlanV2View` as the sole canonical interface.

## Changes
### Features
- Canonical V2 Interface: Standardized `ControlPlanWorkspace.tsx` to unconditionally render `ControlPlanV2View` with full operations navigation, characteristic cards, shared equipment chips, and review decisions.
- Universal V2 Imports & Exports: Updated `validateImport` to validate hierarchical V2 structures and preserved `getDocLines` projection for 26-column XLSX workbook exports and PDF generation.

### Fixes
- Fixed Archived Project 403 Error: Enforced revision writability and project status checks in `cp-review.service.ts` and `cp-approval-package.service.ts`, preventing mutation attempts on read-only archived guest projects.
- Fixed Inverted Prop in Workspace: Removed inverted conditional `document={isCpDocumentV2(document) ? null : ...}` that previously passed `null` to `ControlPlanV2View`.

### Refactors
- Database Table Retirement: Dropped prototype tables `control_plan_row` and `control_plan_pfmea_link` via migration `20261023180000_retire_control_plan_v1`.
- Backend Clean-up: Deleted `control-plan-row.controller.ts` and `control-plan-row.service.ts`; replaced legacy row count checks in `project.service.ts` and `pfd.service.ts` with `operationVersionBinding.count`.
- Frontend Clean-up: Deleted `ControlLineEditor.tsx`; purged all V1 flat-table JSX, legacy line modals, the V1 upgrade alert banner, and the upgrade preview dialog from `ControlPlanWorkspace.tsx`.
- Standardized Types: Consolidated `CpDocument = CpDocumentV2` and `AnyCpDocument = CpDocumentV2` in `controlPlanDocument.ts` with `emptyCpDocumentV2()` and `applyV1ToV2Conversion()`.
