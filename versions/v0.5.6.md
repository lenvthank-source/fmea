# v0.5.6 — 2026-09-01

## Summary
Rebuilt the Process Flow Diagram (PFD) canvas and flowchart engine from scratch to AIAG-VDA and ASME industrial standards matching engineering reference schematics, modernized the PFD workspace, Repository, Actions Dashboard, and Admin panel to the space-optimized Shadcn Admin theme, authored the authoritative UI theme design rule (.agents/rules/ui-theme.md), eliminated double asterisks on required form fields, enabled the Safe Launch Containment Plan across all 3 manufacturing phases (Prototype, Pre-Launch, Production), and made the DocumentHeader sticky, unblurred, and visible above modal backdrops.

## Changes
### Features
- **Industrial Process Flow Diagram (PFD) Rebuild**: Built `PfdEngineeringCanvas.tsx` featuring authentic engineering equipment vector icons (Centrifugal Pumps, Vertical Vessels with agitator, Reactors/Columns, Heat Exchangers with cooling water CW lines, Serpentine Heating Coils/Ovens, In-line Filters, Compressors, Cyclones/Silos, Horizontal Storage Drums, Laser Weld cells, Presses, and Optical Inspection gates), orthogonal process stream piping with 90° bends and directional arrowheads, feed stream flags (e.g. `Sugars`, `Water`) parsed from incoming variation, equipment tagging (`P-101`, `V-101`, `Step 10`), AIAG/ASME standard classification pills (`◯ OPER`, `□ INSP`, `⇨ MOVE`, `▽ STORE`, `☉ DELAY`, `◇ DECIS`, `Ⓡ REW`, `✕ REJ`), and one-click SVG export.
- **Safe Launch Across All 3 Phases**: Enabled Safe Launch Containment Plan modifier across Prototype, Pre-Launch, and Production phases (`Prototype (Safe Launch)`, `Pre-Launch (Safe Launch)`, `Production (Safe Launch)`), with dynamic badge propagation in the DocumentHeader and project tables.
- **Sticky & Unblurred DocumentHeader**: Configured `position: sticky; top: 0; zIndex: 1350` and disabled backdrop blur (`backdrop-filter: none !important`), keeping header details (Part Name, No, Customer, Rev, Status) 100% visible, sharp, and readable even when opening modal dialogs to add failure modes, functions, or steps.
- **Authoritative UI Theme Rule**: Created `.agents/rules/ui-theme.md` establishing strict design tokens, typography, CSS layer separation, form spacing rules, and copy-paste component templates.

### Fixes
- **Eliminated Double Asterisks**: Removed duplicate trailing `*` in TextField labels where MUI's `required` prop automatically appends an asterisk.
- **Modal Backdrop Blurring**: Removed global backdrop blur filters that obscured background and header text during data entry.

### Refactors
- **Modernized Internal Workspace Pages**:
  - `PfdWorkspace.tsx`: Upgraded to `#f4f4f5` segmented pill tabs (`Table View` vs `Process Flow Diagram`), clean `#fafafa` table header with uppercase `0.725rem` labels, and white slide-out drawers with `#e4e4e7` borders.
  - `RepositoryPage.tsx`: Upgraded with space-optimized Shadcn header, segmented pill tabs with pending count badge, search with `⌘K`, and `#fafafa` table header.
  - `ActionsDashboard.tsx`: Upgraded with space-optimized Shadcn header, program selector, segmented pill tabs, and clean status filter chips.
  - `AdminPanel.tsx`: Upgraded with space-optimized Shadcn header, segmented pill tabs for all 7 management tabs, and modernized dialogs.
