# v0.2.0 — 2026-08-26
## Summary
Major feature release implementing complete FMEA workflow with revision control, Excel import/export, guest tenant isolation, and security hardening.

## Changes
### Features
- **Excel Import Wizard** (5-step): Upload → Column Map → Row/Col Select → Diff Preview → Import
  - Auto-map columns by exact header match from customer Excel templates
  - Manual mapping fallback with suggestions
  - Row/column selection with inline editing
  - Diff preview (New/Update/Unchanged/Missing) for Update Existing mode
  - Template download with exact image headers
- **Project Replication** — "Duplicate for new customer" menu action
  - Pre-fills full AIAG quality header from source project
  - Selective document type copy (PFD/PFMEA/DFMEA/Control Plan)
  - Audit log entry with `action: 'replicate'`
- **Work Element Retention** — Architectural fix
  - Repository imports now write to PFD master step
  - Structure-tree additions sync to PFD `Machines/Equipment/Docs` column
  - No orphan work elements (merge-not-replace sync)
- **Failure Linkage Network Diagram** — Zoom/pan + fit-to-view
  - Mouse-wheel zoom-to-cursor, drag-to-pan, toolbar (+/−/Fit)
  - Auto fit-to-view on load
  - Right pane (selection tables) stays fixed
- **PFD/PFMEA Excel Export** — Borders & flow icons
  - Whole-table thick outer border + thin borders on first/last 3 rows
  - Flow icons unified to image glyphs (⇨ ▼ ▼ ▲ ◯ □ ◇ Ⓡ ✕)
- **Revision Workflow** — Submit → In-Review → Approve/Reject
  - Submit draft → In-Review (segregation: submitter ≠ approver)
  - Approve with e-signature (password + comment) → locks revision
  - Reject with mandatory comment
  - Segregation of duties enforced (submitter ≠ approver)
  - Audit trail with e-signature (password hash + timestamp + comment)
- **Semver-safe Revision Numbering** — `major.minor` increment
  - `1.9` → `1.10` (not `2.0`)
  - Format validation `X.Y` with regex
- **Guest Tenant Isolation** — Projects filtered by `createdById`
  - Guest users in `guest-tenant` only see own projects
  - `isGuest` claim propagated via JWT
- **Security Hardening**
  - Helmet, Throttler, CORS allowlist, JWT fail-fast (prod)
  - Removed public `/uploads` static fallback, fail-fast R2
  - JWT secret fail-fast (no hardcoded fallback)
  - FileInterceptor validators (50MB, PDF/PNG/JPEG)
  - CORS restricted to configured origins

### Fixes
- PFMEA revision clone junction gap fixed (copies all 7 junction tables)
- Work element retention: master merge on PFD edit, structure-linkage writes to PFD master
- Dropdown menus in dialogs now anchor below field (MenuProps fix)
- Removed "Description/Specification" column from multi-function add dialog
- Excel export: whole-table thick outer border, first/last 3 rows bordered
- Flow icons in Excel export unified to image glyphs

### Architecture
- **BullMQ + Redis** queues added (lazy, inert without `REDIS_URL`)
- **AuditInterceptor** — automatic audit logging on all write mutations
- **Revision lock enforcement** — `assertRevisionWritable` guards all write paths
- **PFMEA revision clone** — now copies all 7 junction tables
- **TanStack Query** provider + `useQuery` migration (ProjectList migrated)
- **React.lazy + Suspense** for heavy workspaces (PFD/PFMEA/DFMEA/CP/Actions/Admin)
- **RequirePermission** route guard (`/admin` admin-only)
- **Guest isolation** — per-guest project filtering via `createdById`

## Breaking / Notes
- JWT payload now includes `isGuest` boolean
- `AuthContext` no longer decodes JWT client-side for permissions; uses `/auth/me`
- `window.fetch` monkey-patch removed (race condition risk)
- Revision numbering now `major.minor` (e.g., `1.9` → `1.10`)
- Control Plan sync deferred (major architectural change later)
- AuditInterceptor logs all write mutations (opt-in for read)
- Guest users in `guest-tenant` filtered by `createdById`
- File upload: 50MB limit, PDF/PNG/JPEG only
- JWT secrets fail-fast in production (no fallback)
