# v0.7.0 — 2026-10-18

## Summary
Prepares the FMEA Quality Platform for public MVP launch by solving critical ergonomics across viewports (13" laptop 1280x800 to 27" desktop 2560x1440), replacing fake mock dashboard activity with a real database audit log stream, establishing strict role segregation between Admin and browser-only Guest sandboxes, enforcing 24-hour custom project lifecycles with backend auto-archival, and introducing an interactive 7-Step Guided Help Tutorial walkthrough with dedicated Next and Skip All controls.

## Changes
### Features
- **Live Audit Activity Feed**: Connected the dashboard activity widget to live PostgreSQL `audit_log` records via `GET /api/v1/audit-logs/recent?limit=6`, formatting real relative timestamps (`Just now`, `5m ago`), genuine actor emails, and categorized event descriptions.
- **Admin Full Visibility & Global Project Deletion**: Admin (`lenvthank@gmail.com`) can view all projects platform-wide across tenants and guest archives, with unilateral permanent delete capabilities.
- **Ephemeral Guest Sandbox (24h Lifespan)**:
  - Browser-only guest sessions stored strictly in `sessionStorage` (`guest_token`, `guest_refresh_token`). Closing browser tab terminates guest access.
  - Guests see exactly 1 pre-filled Reference Demo Project (`E Vacuum Pump [Reference Demo]`) with real data populated across all 7 AIAG-VDA steps.
  - Guests are limited to creating at most 1 custom project with a strict 24-hour lifetime.
  - Backend auto-archival engine (`autoArchiveExpiredGuestProjects`) detects projects $>24$h old, automatically renames them to `[Guest Archive - <User>] <Project Name> (<DateTime>)`, marks them as `archived`, and preserves them for Admin review only.
- **Interactive 7-Step Guided Tutorial Walkthrough**: Added `FmeaTutorialGuide.tsx` covering all 7 AIAG-VDA steps (Planning 5Ts, Structure Analysis, Function Analysis, Failure Analysis, Risk Analysis, Optimization, Documentation). Every step dialog strictly provides two action controls: **"Next"** and **"Skip All"**. Auto-launches on first guest visit and can be reopened via the "7-Step Guide" toolbar button.
- **High-Density Dashboard Ergonomics**: Condensed KPI summary cards to 72px height, tightened padding across all panels, and reduced button heights so the complete cockpit (KPIs, Project Grid, Activity Feed) fits above the fold on 13" laptop screens (1280x800).

### Fixes
- **BUG-01 (PFD Step Number Truncation)**: Expanded step number column width to 120px with centered badges in `PfdWorkspace.tsx` and removed the 56px hover action box that clipped `OP10`, `OP20`.
- **BUG-02 (PFMEA Sticky Column Bleed-Through)**: Added solid `#ffffff` background with `zIndex: 4` (header) and `zIndex: 2` (body) plus subtle divider box-shadow in `PfmeaWorkspace.tsx`, preventing horizontally scrolled text from colliding with sticky columns.
- **BUG-03 (Control Plan Single-Line Input Clamping)**: Converted tolerance/spec inputs to auto-wrapping multiline textareas (`minRows: 1, maxRows: 4`) with `minWidth: 180` in `ControlPlanWorkspace.tsx`, and rebalanced split-screen ratio to 4:8 for comfortable laptop viewing.
- **BUG-04 (PFMEA Floating Pan Grid Overlay)**: Docked the horizontal pan slider directly into the `TablePagination` row in `PfmeaWorkspace.tsx`, eliminating the floating layer that obscured table data rows.
- **BUG-06 (DocumentHeader Monopolization)**: Condensed collapsed header bar to 46px (`py: 1, px: 2.5`) with full clickable toggle in `DocumentHeader.tsx`, recovering ~180px of vertical workspace.
- **BUG-08 (PFMEA Tree Toolbox Cramping)**: Adjusted tree-to-toolbox grid ratio to 8.8:3.2 in `PfmeaStructureTree.tsx` with concise buttons (`+ Step`, `+ Work Elem`, `+ Function`, `+ Failure`).
- **Demo Admin Authentication**: Configured `lenvthank@gmail.com` with `Admin123!` and updated `Login.tsx` "Fill Admin Credentials" button to fill both email and password for 1-click verification.
- **Reference Project Deletion Guard**: Added non-admin deletion guard in `project.service.ts` to protect the reference demo project from accidental deletion.
