# v0.4.0 — 2026-08-29
## Summary
Introduces portable multi-agent mesh (head orchestrator + 10 specialist agents) that works identically in VS Code, Cursor, Opencode, Gemini CLI and Antigravity 2.0 with any model. Source is Markdown `AGENT.md` (not opencode-only `agent.json`), tri-compatible frontmatter (`mode/mainAgent/kind/tools`), shared file bus `memory/blackboard.md`, dispatch table `context/routing.md` and helper `scripts/dispatch.py`. Also mirrors agents into `.gemini/agents/*.md` for Gemini discovery and adds governance `AGENTS.md:6.5`.
## Changes
### Features
- **Portable orchestrator**: new `.agents/agents/orchestrator/AGENT.md:1` (`mode:primary`, `mainAgent:true`, `kind:local`, `tools:view_file/grep_search/list_dir/send_message`, `max_parallel:4`, `human_gate:always`, `allow/allow_shared`) + `orchestrator/prompt.md:1`. Classifies via `context/routing.md:1`, fans out max 4, merges with priority, enforces human APPROVED gate before build/push.
- **10 specialist AGENT.md**: `.agents/agents/pfd/AGENT.md:1` (PfdModule/PfdWorkspace), `pfmea/AGENT.md:1` (AP, S/O/D [1,10], linkage), `dfmea/AGENT.md:1`, `control-plan/AGENT.md:1` (bidirectional CP), `action/AGENT.md:1` (High AP, R2), `revision/AGENT.md:1` (21 CFR, immutability), `rag/AGENT.md:1` (HNSW M=16), `auth/AGENT.md:1` (72h lastActivityAt), `repository/AGENT.md:1`, `ai-suggestion/AGENT.md:1` — each with `allow` hard fencing, `loads` skill/context slice, `ide:any`, `model:inherit`, portable to any IDE/model.
- **Routing table**: `.agents/context/routing.md:1` — `Keywords→Agent→AGENT.md→Priority→Fencing` (comma-separated keywords, `max_parallel:4`), plus tri-compat mapping table (Opencode Task ≡ Antigravity invoke_subagent ≡ Gemini invoke_agent/@).
- **Blackboard bus**: `.agents/memory/blackboard.md:1` — append-only `## <ISO> — <intent> — <agent> — <status> — priority:N` with `owns/artifacts/depends_on` and `> agent→target: msg` (replaces `send_message` for file-based portability, visible in any IDE terminal).
- **Dispatch helper**: `.agents/scripts/dispatch.py:1` — stdlib, parses `routing.md`, `re.search` intent, caps 4, prints per-agent `AGENT.md` system prompt blocks for copy-paste into any chat, appends `pending` to blackboard (fallback when `Task` not available). Handles Windows `cp1252→utf-8` and comma-→`|` regex.
- **Gemini mirrors**: `.gemini/agents/*.md:1` (11 files) copied from `.agents/agents/*/AGENT.md` for `Gemini CLI` discovery (`.gemini/settings.json:1` already hosts mcpServers neon/context7/cloudflare/playwright).
### Refactors
- **Governance**: `.agents/AGENTS.md:150` add `§6.5 Multi-Agent Orchestration — Portable Mesh` (source truth AGENT.md vs legacy json, mirrors, orchestrator, bus, helper, routing, hard fencing, legacy JSON deprecation, opencode vs gemini parity).
- **Progressive loading**: `.agents/README.md:20` expand context tree (`routing.md`, `dispatch.py`, `blackboard.md`) and L2 table with `Specialist AGENT.md` column (pfd/pfmea/dfmea etc.) + scripts/memory rows.
- **Workflow fencing**: `.agents/workflows/feature.md:1` insert step 0 orchestrator gate (classify via routing.md → blackboard.md, max 4, human APPROVED) and `allow`/`allow_shared` grants via blackboard.

### Fixes
- **Routing parse bug**: fix `routing.md:9` pipe-in-cell split by changing keyword separator from `\|` to `, ` and `dispatch.py:50` `match_agents` to split on comma and join with `|` (prevents markdown table `|` breaking).
- **Dispatch encoding**: fix `UnicodeEncodeError cp1252` for `↔` etc. by `sys.stdout.reconfigure(utf-8, replace)` in `dispatch.py:7`.
