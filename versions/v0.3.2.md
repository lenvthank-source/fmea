# v0.3.2 — 2026-08-27
## Summary
Renames programmatic '[Orphaned]' references to domain-accurate '[PFD Detached]', introduces a minimalist close-to-click warning confirmation modal, polishes the PFD Import Wizard (step-based mode chip timing, high-contrast diff formatting, column borders), adds bold dividers and section badges to the Failure Linkage diagram, enables dynamic Report View Status computation with persistence, and fixes dialog Y-axis shift with downward dropdown menu anchoring.
## Changes
### Features
- **Domain Terminology `[PFD Detached]`:** Replaced programmatic `[Orphaned]` text with automotive quality domain label `[PFD Detached]` across `PfmeaStructureTree.tsx:489`, `ControlPlanWorkspace.tsx:566`, and `PfmeaWorkspace.tsx:929` with descriptive tooltips explaining PFD step detachment.
- **Minimalist Warning / Deletion Dialog:** `frontend/src/components/ConfirmDialog.tsx:1` redesigned into an ultra-compact, professional confirmation modal shifted closer to click focus (`transform: 'translateY(-24px)'`) with clean typography and streamlined Cancel/Delete buttons.
- **PFD Import Wizard Polish:** `frontend/src/features/pfd/components/ExcelImportWizard.tsx:965,1109,1253` mode chip hidden on Steps 0 & 1 and shown from Step 2 onwards (`activeStep >= 2`), diff table `CHANGES` column updated with high-contrast strike-through diff cards, and vertical borders added across all table columns.
- **Failure Linkage Bolder Dividers & Banners:** `frontend/src/features/pfmea/components/FailureLinkageModal.tsx:424,653,734` upgraded canvas divider to `3px solid #94A3B8`, added `3px solid #CBD5E1` horizontal block divider, and styled header badges for Higher Level Effects and Lower Level Causes.
- **Dynamic PFMEA Report View Status:** `frontend/src/features/pfmea/PfmeaWorkspace.tsx:202,1627` added `getDynamicRowStatus` to derive status (`—`, `Open`, `In Progress`, `Completed`, `Closed`) from action fields, and updated `handleSaveManageAction` to persist manual status changes.
- **Dialog Position & Dropdown Anchoring:** `frontend/src/theme/muiSelectConfig.ts:1` added `maxHeight: 280` and downward anchoring (`anchorOrigin: { vertical: 'bottom', horizontal: 'left' }`, `transformOrigin: { vertical: 'top', horizontal: 'left' }`), and added `transform: 'translateY(-36px)'` to `AddFailureDialog.tsx:315`, `AddFunctionDialog.tsx:221`, and `MultiAddWorkElementDialog.tsx:180`.
### Refactors
- **Status DTO Validation:** `backend/src/modules/pfmea/dto/update-pfmea-row.dto.ts:101` expanded allowed status strings to accept action states (`Open`, `In Progress`, `Completed`, `Verified`, `Closed`).
