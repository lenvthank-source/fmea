# Templates for Agentic Architecture

This directory contains reference markdown templates utilized by `scaffold_architecture.py` and human architects when creating new subsystems, specialist personas, system rules, and memory specifications.

## Directory Structure
- `agents/persona.md.template`: Template for domain-specialist agent personas.
- `memory/subsystem_spec.md.template`: Template for deep mathematical/algorithmic subsystem specs.
- `rules/coding-style.md.template`: Language-agnostic coding style and zero-stub rule template.
- `checklists/pre-commit.md.template`: Pre-commit verification checklist template.
